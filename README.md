# 进度看板 · Panel

一个**单文件**的论文 / 项目进度看板：任务列表、看板、时间轴三种视图，数据全部保存在浏览器本地，**无需注册、无需后端**，还能安装成桌面应用（PWA）。

**在线使用：** <https://seven-70.github.io/Panel/>

---

## 功能

- **三种视图**：任务列表 / 看板视图 / 时间轴
- **任务管理**：状态（待开始 → 进行中 → 已完成，另有待修改）、优先级（紧急 / 重要 / 常规）、所属阶段、截止时间
- **日历 + 倒计时**：按截止日期显示最近任务的倒计时；点某个日期查看当天任务，同一日期多条时只显示其中一条
- **任务统计**：环形图展示各状态占比，点扇区即可按状态筛选
- **筛选与搜索**：按 状态 / 优先级 / 时间 组合筛选，按名称搜索；视图与筛选状态会记住，刷新后自动恢复
- **批量管理**：多选后统一改状态、优先级或删除
- **导入任务**：把大纲 / Markdown 文本一键转成任务，支持「只保留大标题」「只取冒号前的标题」两个开关，可逐条设置所属阶段
- **备份与恢复**：导出 / 导入 JSON 备份，也支持把备份文件拖进弹窗或直接粘贴内容
- **细节**：明暗主题、备忘录、悬停提示，以及键盘操作（`Enter` 打开任务、`Delete` 删除、`Alt` + `↑/↓` 调整顺序、`Esc` 关闭弹窗）

## 数据说明（重要）

- 所有任务、备忘录等内容**只保存在你自己的浏览器本地**（localStorage），**不上传、不共享、不跨设备同步**。
- 把链接发给别人，对方打开看到的是一份**空白看板**，你们各自的记录互不可见、互不影响。
- 清理浏览器数据、使用无痕 / 隐私模式或卸载应用，会导致数据丢失且无法找回。
- 建议定期用「备份设置 → 导出备份」留一份 JSON 备份；换设备时在新设备里拖入或粘贴该备份即可恢复。

## 安装到桌面（PWA）

1. 用 Chrome / Edge 打开 <https://seven-70.github.io/Panel/>
2. 地址栏右侧点「安装」图标，或浏览器菜单 →「安装进度看板 / 将此站点作为应用安装」
3. 安装后以**独立窗口**运行、没有地址栏，并支持离线使用

> **手机 / 平板不建议使用**：界面按桌面宽屏设计，小屏体验较差。
> 提示：安装前需先用浏览器联网打开本页一次，之后才能离线使用。

| `manifest.json` | PWA 清单 |
| `sw.js` | Service Worker，负责离线缓存 |
| `icon-192.png` / `icon-512.png` | 应用图标 |

## 使用与二次修改

- 用浏览器直接打开 `index.html` 也能用（本地 `file://` 打开时不注册 PWA，保持纯单文件离线）。
- 没有任何外部依赖：无 CDN、无网络字体，全部是原生 HTML / CSS / JavaScript + SVG。
- 更新线上版本：替换仓库里的 `index.html` 即可，其余文件通常无需改动。
